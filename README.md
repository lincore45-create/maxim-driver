# Maxim Driver Promo game

Мобильная веб-игра для промо-акций Maxim Thailand: участник сканирует QR, играет на своём телефоне и показывает финальный экран промоутеру, чтобы получить промокод.

- 10 км трассы, +100 очков за километр, +10 за уворот в последний момент
- Номиналы: 1 км — 50 ฿, 5 км — 200 ฿, финиш — 500 ฿
- 3 жизни, управление кнопками или наклоном телефона
- Языки: тайский, английский, русский
- Low-poly графика в стиле PS1, вся генерируется кодом

## Как поиграть
Откройте ссылку GitHub Pages на телефоне в портретной ориентации. На компьютере можно играть стрелками или WASD.

## Как настроить баланс
Все параметры (скорость, частота препятствий, длина гонки, пороги номиналов, крупность пикселей) — в объекте `CONFIG` в начале скрипта в `index.html`.

## Технически
Один файл `index.html`: HTML5 Canvas + Web Audio, без движков и зависимостей (кроме шрифтов Google Fonts). Бэкенд не нужен.
